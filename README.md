# DroneController_Docs

Public documentation for **DronController**.

- **`slides.json`** (repo root) — the rotating tips shown in the DronController **launcher**'s documentation
  panel. The launcher fetches it from
  `https://raw.githubusercontent.com/miagton/DroneController_Docs/main/slides.json` on every launch, so edits
  here go live next launch (no app release). A slide's `url` opens the matching page; a slide without a `url`
  opens the wiki home.
- **[Wiki](https://github.com/miagton/DroneController_Docs/wiki)**: the full guide, in two sections:
  **Operator** (driving, video, network status; everyone) and **Engineer** (admin setup). Every page is EN + `-UA`.

## Wiki conventions
The wiki is its own git repo: `https://github.com/miagton/DroneController_Docs.wiki.git`.
- **Layout:**
  - `Home`, `_Sidebar` and `images/` at the root;
  - pages in `Operator/` and `Engineer/`.
- **Page names:** wiki URLs are flat, so names must be unique across folders (`Operator-*`, `Engineer-*`). Links use the bare name: `[HUD](Operator-HUD)`.
- **Images:** embed them by URL, `https://raw.githubusercontent.com/wiki/miagton/DroneController_Docs/images/<file>.png`, because relative paths don't resolve reliably from subfolders.
  - `op-*` is the operator view;
  - `eng-*` is the admin view;
  - no prefix means the image is the same for both.
- **Screenshots:** generated by `tools/docs/capture.py` in the main DroneController repo, from neutral sample data. Live-app shots (HUD, calibration, intro/exit) are taken in Play mode with the map's GPS source on the fake board. **Never publish real tunnel names, addresses, endpoints or positions.**
- **Before pushing:** run `python tools/docs/checklinks.py` from the main repo. It checks every page and image link and this repo's `slides.json`.
- **Launcher fallback:** the launcher embeds a copy of `slides.json` (`DronLauncher/slides.json` in the main repo) for offline use. Keep the two identical.

## Editing `slides.json`

```json
{
  "docsUrl": "https://github.com/miagton/DroneController_Docs/wiki",
  "background": null,
  "slides": [
    {
      "title": "Short heading", "text": "A sentence or two.",
      "title_uk": "Короткий заголовок", "text_uk": "Речення-два.",
      "url": ".../wiki/PageName", "image": null
    }
  ]
}
```

The launcher shows **both languages** on each slide. `title_uk` / `text_uk` are optional — omit them and only
English is shown. Keep `title` to one line and `text` to a sentence or two — the launcher panel is compact.
`image` / `background` are reserved for a future visual phase and ignored for now.
